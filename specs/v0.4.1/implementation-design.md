# v0.4.1 实现设计：双语界面与指标说明

> 状态：已确认，实施中。

## 目标

在不改变指标事实、人工阈值、双轴市场状态或 AI 判断逻辑的前提下，让公开用户可在中文和英文之间切换，并以固定的三栏结构阅读每个指标。

## 前端结构

- 新增前端语言资源，按稳定的指标 ID 保存界面文字、指标名称、公式补充、普通语言含义和使用限制；数字、公式本体、阈值和来源 URL 仍来自现有数据包。
- 语言选择默认中文，写入浏览器本地存储。切换语言时不重置当前分类、指标、图表控制或详细分析展开状态。
- `MetricExplanation` 固定渲染“指标公式、指标含义、指标使用”三栏；来源作为三栏外的独立区域，保留分类、证据角色和阈值信息但不把它们伪装成普通语言解释。
- 桌面端三栏并列，窄屏端纵向堆叠。

## 英文 AI 分析

- 每日流程先生成并校验中文分析；通过后以中文分析对象为唯一输入，调用同一受控模型服务生成字段结构一致的英文翻译。
- 英文翻译不得修改压力状态、筑底状态、一致性、日期、分类状态或状态变化，只翻译可读文本字段。
- 翻译失败不会让当天中文分析失败；数据包记录英文分析不可用原因，英文界面展示清楚的不可用提示。
- 本地 `--mock-ai` 生成稳定的英文翻译夹具，不可将其称为真实模型调用。

## 验证

- Python 合约验证中英文分析的状态字段一致，并验证翻译失败的降级行为。
- 前端构建验证类型与产物；浏览器验收覆盖默认中文、切换英文、刷新保持、说明栏三栏、来源位置和窄屏布局。
