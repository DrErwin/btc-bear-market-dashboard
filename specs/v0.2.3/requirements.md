# v0.2.3 — 图表布局与状态配色

> 状态：已实现。基于 v0.2.2 的前端使用反馈，本版只修改图表呈现与交互，不改变数据来源、AI 判断或数据包格式。

## 1. 删除图表标题下的重复说明

删除指标标题下的“BTC 价格 + 指标 + 配置阈值 + 历史熊底虚线”整行说明，保留指标名称、图例和图表事实栏。

## 2. 图表高度可调整并记忆

- 默认高度为 `420px`，允许范围为 `320–760px`。
- 图表底部提供鼠标/触摸拖动手柄：向下拖动增高，向上拖动降低。
- 手柄支持键盘：`ArrowUp`/`ArrowDown` 每次调整 `24px`，`Home`/`End` 直接到最小/最大高度。
- 高度保存到浏览器 `localStorage` 的 `btc-dashboard.chart-height.v1`；缺失、非法或超范围值恢复默认高度。
- 全屏时使用屏幕可用高度，退出全屏后恢复保存的普通高度。

## 3. 柱状图在主图底部显示

- HODLer 柱状数据使用 `hodler_npc_30d`，≥155d 柱状数据使用 `spent_value_ge155d_share`。
- 只在 `hodler` 和 `spent155` 指标中显示柱状图；选择 `hodler` 时只显示 HODLer 柱，选择 `spent155` 时只显示 ≥155d 柱，且图例开关与当前柱状系列一一对应。
- 当前指标对应的柱子与 BTC 价格共用同一个绘图区和时间轴，位于主图底部，不建立第二个绘图区；HODLer 与 ≥155d 不在同一页面同时显示。
- 选中这两个柱状指标时，不再渲染该指标的橙色指标线，也不显示它对应的阈值线开关；保留 BTC 价格线、历史熊底线和当前对应柱子作为上下文。
- 当前柱子使用与自身数据对应的右侧独立纵坐标，并将显示范围扩展到绘图区下方约 40%；无用的指标刻度轴隐藏，保持主曲线可读。
- 缺失日期保持为空，不前向填充；当前时间范围没有柱状数据时显示提示，引导切换到全量范围。

## 4. 观察区只用字体颜色区分

指标列中：未进入观察区使用灰色，进入观察区使用橙色，重点观察区使用红色；不再给文字增加背景色块。
