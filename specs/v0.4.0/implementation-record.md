# v0.4.0 — 实现记录

> 状态：已在本地实现并通过统一自动验收；尚未进行真实模型认证、线上部署或公开数据授权变更。

## 1. 业务结果

v0.4.0 把“熊底”看成一个可能反复的过程，而不是需要猜中的单一时刻。页面和每日结果包现在分别回答：

- 压力轴：市场承受的压力有多深；
- 筑底轴：熊底证据形成到什么程度，是否进入修复并离开熊底窗口。

两条轴可以处于不同位置。AI 只在固定双轴词汇表内做定性综合，解释证据如何组合；机器负责提供事实、保护阈值和数据边界，不提供预先算好的总阶段、分数或交易动作。

## 2. 已实现范围

- 16 个指标保留原有阈值数值、方向、顺序和人工校准的“观察／深度压力／极端压力”含义。
- 每个指标有稳定的档位身份、一个主要证据职责和相关性家族，避免只因标签改名而改变含义，也避免相关指标被重复当成独立证据。
- 数据质量按压力轴和筑底轴分别判断；关键数据不足时可只限制对应轴，并在结果包中明确说明。
- 使用经过本地固定夹具验证的 730 日时间窗口，提供有限的进入、加强、减弱、反转、修复和离开窗口事实，不把完整历史序列发送给 AI。
- 每日提供最近三个自然日上下文；缺失日期明确标记，不用猜测补齐。
- AI 输出包含双轴状态、证据一致性、简短结论、状态变化原因，以及六段可展开的详细解释。
- 页面、AI 和回退结果共同读取同一份完整结果包；旧 v0.3 单一 `stage`／`allowed_stages` 输入会被拒绝。
- 稳定档位 ID 驱动页面颜色，阈值显示名称可以调整而不改变历史语义。

- 本次没有新增或改变数据源授权；公开缓存、静态包和第三方数据的授权仍按既有发布审查处理。
