# BTC 熊底证据看板

**BTC 熊底证据看板（BTC Bear-Bottom Evidence Dashboard）**是一个公开、只读的比特币链上周期研究工具。它把分散的 BTC 链上指标整理成可检查的证据，帮助普通用户理解两个不同问题：**当前市场压力有多深，以及熊市筑底过程走到了哪里。**

[打开 BTC 熊底证据看板](https://btc-bear-market-dashboard.erwinwu000.workers.dev/)

> [!IMPORTANT]
> 这是研究型市场状态看板，不是交易信号工具。它不预测精确最低点，也不提供买卖、仓位、杠杆、价格目标或择时建议。

## 这个看板解决什么问题？

判断 BTC 熊市时，人们经常把“市场已经很便宜”“卖方压力很大”和“熊底已经形成”混成同一件事。但熊底通常不是一个瞬间，而是一段由压力、投降、承接和修复共同组成的过程。

这个看板把结论拆成两条独立的市场状态轴：

- **压力轴**：压力尚未明显、进入观察、深度压力、极端压力或数据不足。
- **筑底过程轴**：未见筑底结构、筑底线索出现、筑底证据聚合、筑底证据较完整、市场修复中、已离开底部窗口或数据不足。

两条轴可以处在不同位置。例如，市场可能已经进入深度压力，但筑底证据仍然不足；也可能压力开始缓解，但市场仍在修复过程中。

## 核心功能

- **双轴市场状态**：分别描述 BTC 市场压力和熊底形成过程，不把复杂市场压缩成单一“见底／未见底”。
- **16 项周期指标**：覆盖市场估值与成本、供应盈亏、链上资本流、持有者行为、矿工压力和长期成本锚。
- **人工校准阈值**：每项指标保留观察、深度压力和极端压力等历史阈值，用于理解指标当前处在什么位置。
- **AI 综合解读**：AI 在固定事实和安全边界内解释当前状态、相反证据、数据缺口、近三日变化，以及修复是否持续。
- **指标通俗解释**：每项指标均提供“指标公式、指标含义、指标使用”和独立来源，方便普通用户理解与复核。
- **中英文界面**：支持中文和 English，指标数值、阈值和市场状态在切换语言后保持一致。
- **历史共享图表**：把 BTC 价格、指标曲线、历史熊底参考和阈值放在同一时间范围内检查。
- **数据质量提示**：缺失、过期或仅供展示的数据会明确标记，不会被当作当前市场证据。

## 看板包含哪些 BTC 指标？

看板使用的指标包括 MVRV、AVIV、STH-MVRV、盈利供应占比（PSIP）、相对未实现盈利与亏损、aSOPR、已实现市值变化、HODLer 行为、老币花费占比、Seller Exhaustion Constant、Puell Multiple、Thermocap Multiple、CVDD 和 Reserve Risk 等。

这些指标不是被机械相加或计票。高度相关的指标只用于相互复核，AI 会优先观察来自不同市场维度的证据是否一致。

## 如何阅读看板？

1. 先看压力轴，了解全市场成本、亏损和矿工收入压力是否加深。
2. 再看筑底过程轴，判断投降、卖方耗竭、承接和修复证据是否正在形成。
3. 查看近三日变化，了解状态是否延续，以及变化原因。
4. 进入单项指标，核对当前值、阈值、日期、公式、含义、使用限制和来源。

## 常见问题

### 它能找到 BTC 最低点吗？

不能。看板描述市场压力和筑底过程，不预测某一天或某个价格就是最低点。

### 为什么需要压力轴和筑底过程轴？

因为“压力很深”只说明市场承受较大亏损或收入压力，并不等于卖方耗竭、承接和修复已经完成。两条轴可以避免把压力误认为熊底确认。

### AI 会修改指标阈值吗？

不会。指标数值、阈值方向、数据日期和可用性由事实数据提供；AI 只负责在限定框架内解释证据。

### 这是投资建议或抄底工具吗？

不是。看板不输出买卖动作、仓位建议、杠杆建议、价格预测或成功概率。

## English summary

The **BTC Bear-Bottom Evidence Dashboard** is a public, read-only Bitcoin on-chain cycle research tool. It uses 16 indicators to describe two independent questions: **how deep current market pressure is, and how far the bear-market bottoming process has progressed**. It provides bilingual explanations, historical charts, threshold context, data-quality labels, and bounded AI analysis. It does not predict an exact Bitcoin bottom and does not provide trading advice.
